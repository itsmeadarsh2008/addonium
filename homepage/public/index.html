Addonium

A freedom-first addon/module schema for music applications.

Spec 1.0.0-draft · Spec text CC0-1.0 · Code Apache-2.0

Install an addon

  1. Paste a base URL or manifest.json URL (Open or tokenized Locked addon).
  2. Or import a .aium module + separate .aiumkey key.

Read the spec · API info

Author in 60 seconds

{
  "addonium": "1.0",
  "id": "club.example.openradio",
  "name": "Open Radio",
  "version": "1.0.0",
  "type": "open",
  "auth": null,
  "baseUrl": "https://openradio.example.com",
  "resources": ["search", "stream"]
}

Validate: bunx ajv-cli validate -s schema/addonium.schema.json -d manifest.json
